ADMIN TI
■ Workflow
    • Ingresa al módulo de profesionales.
    • Selecciona Registrar profesional.
    • Ingresa los datos.
    • Selecciona Guardar.
    • El sistema valida.
    • Registra al profesional.
    •
■ Business Logic
    • El profesional debe quedar asociado a la peluquería.
    •
■ Decisions
    • IF los datos son válidos → registra.
    • ELSE IF falta información → solicita completarla.
    • ELSE no registra.
    •
■ Follow-up
    • El profesional puede ser seleccionado por los clientes.

Cliente
Steps
1. 1. El cliente selecciona Registrarse.
2. 2. Ingresa nombre completo.
3. 3. Ingresa documento.
4. 4. Ingresa correo electrónico.
5. 5. Ingresa teléfono.
6. 6. Ingresa contraseña.
7. 7. Selecciona Registrar.
8. 8. El sistema valida la información ingresada.
9. if todos los campos obligatorios están completos
    9.1. if el correo no está registrado
        9.1.1. registra el usuario.
        9.1.2. informa que el registro fue exitoso.
    9.2. else
        9.2.1. informa que el correo ya está registrado.
         end if
10. else
    10.1. solicita completar los campos obligatorios.
    end if

AdminPe
Steps
1. 1. El administrador de peluquería selecciona Registrar usuarios.
2. 2. Ingresa los datos requeridos del usuario.
3. 3. Selecciona Registrar.
4. 4. El sistema valida los datos.
5. if todos los campos obligatorios están completos
    5.1. if el correo no esta registrado
        5.1.1. registra el usuario
        5.1.2. informa quue el registro fue exitoso
    5.2. else
        5.2.1. informa que el correo ya esta registrado
         end if
6. else
    6.1. solicita completar los campos obligatorios
   end if
