Database Tables
Name Description
 Fotospe : Entity 		Almacena las fotografías correspondientes a una peluquería.
 Solicitudafi : Entity 		Almacena las solicitudes realizadas por propietarios que desean afiliar una peluquería a Glow.
 Fotosser : Entity 		Almacena las fotografías relacionadas con los servicios.
 Categoria : Entity 		Clasifica los servicios de la peluquería.
 login : Entity 		Controla las credenciales de acceso de los usuarios.
 Trabajador_Servicio : Entity 		Esta tabla permite establecer la relación entre trabajadores y servicios.
Es necesaria porque un trabajador puede prestar varios servicios y un servicio puede ser realizado por diferentes trabajadores.
 Horario : Entity 		Almacena los horarios de trabajo de los profesionales.
 Reserva_Servicio : Entity
Relaciona una reserva con el servicio que será prestado y con el profesional que lo realizará.
Esta tabla es importante porque una reserva puede involucrar un servicio específico, un profesional y un horario determinado.
 Cliente : Entity 		La tabla Cliente almacena la información personal de las personas que utilizan el sistema para solicitar y gestionar citas.
 Peluqueria : Entity 		Almacena la información de cada peluquería afiliada al sistema.
 Reserva : Entity 		La tabla Reserva representa una cita realizada por un cliente.
 Tipodocumento : Entity 		Almacena los tipos de documento de identificación que pueden utilizar los clientes.
 Servicio : Entity 		Almacena los servicios ofrecidos por una peluquería.
 Ciudad : Entity 		Permite almacenar las ciudades donde existen peluquerías inscritas en nuestro aplicativo web.
 Trabajador : Entity 		Almacena los profesionales o trabajadores que prestan servicios en una peluquería.
 Estadocita : Entity 		Almacena los estados posibles de una cita.
