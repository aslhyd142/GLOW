Use Case Note
■ Workflow
    • El usuario selecciona Recuperar contraseña.
    • Ingresa su correo.
    • El sistema verifica el correo.
    • El sistema genera un enlace.
    • Envía el enlace al correo.
    • El usuario accede al enlace.
    • Ingresa una nueva contraseña.
    • El sistema actualiza la contraseña.
    •
■ Business Logic
    • El enlace debe enviarse al correo registrado.
    • La nueva contraseña debe cumplir las condiciones establecidas.
    •
■ Decisions
    • IF el correo existe → envía el enlace.
    • ELSE IF el correo no existe → informa el error.
    • ELSE no genera el enlace.
    •
■ Follow-up
    • El usuario puede iniciar sesión con la nueva contraseña
    •

Scenario
Steps
1. 1. El usuario selecciona Recuperar contraseña.
2. 2. Ingresa correo electrónico.
3. 3. El sistema verifica el correo.
4. if el correo está registrado
    4.1. genera un enlace de recuperación.
    4.2. envía el enlace al correo registrado
    4.3. el usuario accede al enlace.
    4.4. ingresa una nueva contraseña.
    4.5. if la contraseña cumple las condiciones establecidasactualiza la contraseña.
        4.5.1. actualiza la contraseña.
        4.5.2. informa que la contraseña fue actualizada
    4.6. else
        4.6.1. solicita ingresar una contraseña válida.
         end if
5. else
    5.1. informa que el correo no está registrado.
   end if
