Use Case Note
■ Workflow
    • Ingresa al módulo de servicios.
    • Selecciona Registrar servicio.
    • Ingresa el nombre.
    • Ingresa la descripción.
    • Ingresa el precio.
    • Selecciona Guardar.
    • El sistema valida.
    • Registra el servicio.
    •
■ Business Logic
    • El nombre y precio son obligatorios.
    • El servicio debe quedar asociado a la peluquería.
    •
■ Decisions
    • IF los datos son válidos → registra.
    • ELSE IF falta información → solicita completarla.
    • ELSE no registra.
    •
■ Follow-up
    • El servicio puede ser consultado por los clientes.
    •

Scenario
Steps
1. 1. El administrador de peluquería selecciona Registrar servicio.
2. 2. Ingresa el nombre del servicio.
3. 3. Ingresa la descripción.
4. 4. Ingresa el precio.
5. 5. Ingresa la duración.
6. 6. Selecciona Registrar.
7. 7. El sistema valida los datos.
8. if los datos son válidos
    8.1. if el servicio no esta registrado
        8.1.1. registra el servicio
        8.1.2. informa que el servicio fue registrado
    8.2. else
        8.2.1. informa que el servicio ya esta registrado
         end if
9. else
    9.1. solicita corregir la informacion
   end if
