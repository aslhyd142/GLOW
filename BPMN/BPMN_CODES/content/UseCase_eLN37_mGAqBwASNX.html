Use Case Note
■ Workflow
    • El profesional consulta su agenda.
    • Selecciona una cita.
    • El sistema muestra la información.
    • El profesional consulta los datos.
    •
■ Business Logic
    • El profesional solo puede consultar citas asociadas a él.
    •
■ Decisions
    • IF la cita pertenece al profesional → muestra la información.
    • ELSE no permite la consulta.
    •
■ Follow-up
    • El profesional puede atender el servicio.
    •

Scenario
Steps
1. 1. El profesional selecciona una cita.
2. 2. Selecciona Consultar cita.
3. 3. El sistema verifica la información de la cita.
4. if la cita existe y pertenece al profesional
    4.1. muestra la informacion de la cita
5. else
    5.1. informa que la cita noo esta disponible
   end if
