Use Case Note
■ Workflow
    • El usuario selecciona Iniciar sesión.
    • Ingresa su correo.
    • Ingresa su contraseña.
    • Selecciona Ingresar.
    • El sistema valida las credenciales.
    • El sistema identifica el rol.
    • El sistema permite el acceso.
    •
■ Business Logic
    • Solo los usuarios registrados pueden acceder.
    • El acceso depende del rol asignado.
    •
■ Decisions
    • IF las credenciales son correctas → permite el acceso.
    • ELSE IF el correo no existe → muestra error.
    • ELSE IF la contraseña es incorrecta → muestra error.
    • ELSE solicita nuevamente las credenciales.
    •
■ Follow-up
    • El usuario accede al panel correspondiente a su rol.
    •
