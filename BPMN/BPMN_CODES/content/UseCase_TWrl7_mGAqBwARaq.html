AdminGeneral
■ Workflow
    • El administrador consulta la peluquería.
    • Selecciona Modificar peluquería.
    • Modifica la información.
    • Selecciona Guardar.
    • El sistema valida.
    • Actualiza la información
    •
■ Business Logic
    • Los datos deben ser válidos.
    •
■ Decisions
    • IF los datos son válidos → actualiza.
    • ELSE IF falta información → solicita corregir.
    • ELSE conserva los datos anteriores.
    •
■ Follow-up
    • La información actualizada se muestra en la plataforma.
    •

AdminPeluqueria
■ Workflow
    • Ingresa al perfil de la peluquería.
    • Selecciona Modificar peluquería.
    • Modifica los datos.
    • Selecciona Guardar.
    • El sistema valida.
    • Actualiza la información.
    •
■ Business Logic
    • La información debe pertenecer a la peluquería administrada.
    • Los datos deben ser válidos.
    •
■ Decisions
    • IF los datos son válidos → actualiza.
    • ELSE IF falta información → solicita completarla.
    • ELSE conserva la información anterior.
    •
■ Follow-up
    • Los cambios aparecen en el perfil del salón.
    •

Admin Peluqueria
Steps
1. 1. El administrador general selecciona una peluquería.
2. 2. Selecciona Modificar peluquería.
3. 3. Modifica la información de la peluquería.
4. 4. Selecciona Guardar.
5. 5. El sistema valida los datos.
6. if los datos son válidos
    6.1. actualiza la información de la peluquería.
    6.2. informa que los cambios fueron guardados.
7. else
    7.1. solicita corregir los datos
   end if

   end if
