Use Case Note
■ Workflow
    • El administrador ingresa al módulo de solicitudes.
    • Selecciona Consultar solicitudes.
    • El sistema busca las solicitudes.
    • Muestra el listado.
    • El administrador consulta una solicitud.
    •
■ Business Logic
    • Deben mostrarse las solicitudes recibidas.
    • La información debe conservarse íntegra.
    •
■ Decisions
    • IF existen solicitudes → muestra el listado.
    • ELSE informa que no existen solicitudes.
    •
■ Follow-up
    • El administrador puede aceptar o eliminar una solicitud.
    •

Scenario
Steps
1. 1. El administrador general selecciona Consultar solicitudes de afiliación.
2. 2. El sistema consulta las solicitudes registradas.
3. if existen solicitudes pendientes
    3.1. muestra las solicitudes pendientes.
    3.2. if existen solicitudes registradas con otro estado
        3.2.1. muestra las solicitudes registradas.
        3.2.2. else informa que no existen solicitudes.
               end if
         end if
   end if
