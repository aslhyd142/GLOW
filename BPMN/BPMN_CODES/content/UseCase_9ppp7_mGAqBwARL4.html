Use Case Note
■ Workflow
    • El cliente consulta sus citas.
    • Selecciona una cita.
    • Selecciona Cancelar cita.
    • El sistema solicita confirmación.
    • El cliente confirma.
    • El sistema cancela la cita.
    • El sistema actualiza la disponibilidad.
    •
■ Business Logic
    • Solo el cliente asociado puede cancelar su cita.
    • Una cita cancelada no debe permanecer como reserva activa.
    •
■ Decisions
    • IF el cliente confirma → cancela.
    • ELSE conserva la cita.
    • ELSE IF la cita ya está cancelada → informa el estado.
    •
■ Follow-up
    • El sistema puede enviar una notificación sobre la cancelación.
    •

AdminPeluqueria
■ Workflow
    •
    • Consulta las citas.
    • Selecciona una cita.
    • Selecciona Eliminar cita.
    • El sistema solicita confirmación.
    • Confirma.
    • El sistema elimina la cita.
    • Actualiza la disponibilidad.
    •
■ Business Logic
    • La eliminación requiere confirmación.
■ Decisions
    • IF confirma → elimina.
    • ELSE conserva la cita.
    •
■ Follow-up
    • El horario puede quedar disponible nuevamente.
    •

Profesional
■ Workflow
    • 1.1. El profesional consulta su agenda, selecciona la cita que desea cancelar y confirma la cancelación. El sistema actualiza el estado de la cita y libera el horario.
        ♦ 1.2. El sistema muestra un mensaje confirmando que la cita fue cancelada correctamen
■ Business Logic
    • 2.1. Cuando el profesional cancela una cita, el sistema debe cambiar su estado a cancelada y dejar disponible nuevamente el horario.
    • 2.2. El sistema debe verificar que la cita seleccionada corresponda al profesional antes de permitir la cancelación.
■ Decisions
    • 3.1. El profesional debe confirmar la cancelación antes de que el sistema realice el cambio.
        ♦ 3.2. Una cita cancelada debe liberar el horario para que pueda estar disponible nuevamente.
    •
■ Follow-up
    • 4.1. Verificar que las citas canceladas actualicen correctamente la disponibilidad de horarios.
    • 4.2. Revisar en la próxima reunión si se requiere notificar al cliente cuando el profesional cancela una cita.

Cliente
Steps
1. 1. El cliente selecciona una cita.
2. 2. Selecciona Cancelar cita.
3. 3. El sistema solicita confirmación.
4. if el cliente confirma la cancelación
    4.1. cancela la cita
    4.2. libera el horario
    4.3. informa que la cita fue cancelada
5. else
    5.1. conserva la cita
   end if

Steps
1. 1. El administrador de peluquería selecciona una cita.
2. 2. Selecciona Cancelar cita.
3. 3. El sistema solicita confirmación.
4. if el administrador confirma la cancelación
    4.1. cancela la cita
    4.2. libera el horario
    4.3. informa que la cita fue cancelada
5. else
    5.1. conserva la cita
   end if

Profesional
Steps
1. 1. El profesional selecciona una cita.
2. 2. Selecciona Cancelar cita.
3. 3. El sistema solicita confirmación.
4. if el profesional confirma la cancelación
    4.1. cancela la cita
    4.2. libera el horario
    4.3. informa que la cita fue cancelada
5. else
    5.1. mantiene la cita
   end if
